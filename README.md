# Beer Pong (mobile)

Pass-the-phone beer pong. Open the link below on your iPhone in Safari.

## Play on your phone

**https://seanholt111.github.io/beer-pong/**

1. Open that link in Safari
2. Set names → Start Game
3. Drag back like a slingshot, release to throw
4. Pass the phone after each shot and tap **I'm ready**
5. Optional: Share → Add to Home Screen

## Repo

Source: this repo. Single `index.html`, no build step.
