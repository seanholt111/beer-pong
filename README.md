# Beer Pong (mobile)

Pass-the-phone beer pong with a **pseudo-3D** table view. Single `index.html`, no build step / no CDN. Tuned for iPhone Safari.

## Play on your phone

**https://seanholt111.github.io/beer-pong/**

1. Open that link in Safari
2. Set names → Start Game
3. Drag back on the lower half (pull = power, left/right = aim), release to throw an arc
4. Pass the phone after each shot and tap **I'm ready**
5. Optional: Share → Add to Home Screen

## Controls

- **Aim:** touch-drag in the lower portion of the table
- **Re-rack:** pack remaining cups into a tight triangle
- **Menu:** back to name screen
